# <i class="fas fa-tools"></i>Software and Database

**[DRS_RNA_landscape](https://zhangtianyuan666.github.io/DRS_doc) (iMeta, 2026, in press):**
Nanopore direct RNA sequencing and the epitranscriptome: Advances in mapping native RNA landscapes.

**[NanoNm](https://github.com/kaifuchenlab/NanoNm) (Molecular Cell, 2024):**
A machine learning model to detect the RNA modification 2'-O-methylation (Nm) in Nanopore direct RNA sequencing data.

**[Nm dection pipeline with NanoNm](https://github.com/YanqiangLi/STAR_Protocol) (STAR Protocols, 2024):**
Protocol for mapping 2′-O-Methylation using nanopore direct RNA-seq data with NanoNm.
